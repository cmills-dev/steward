# Steward launch media

The short cuts introduce Steward and link to its downloadable preview.

- `steward-short-landscape.mp4`: 1920 by 1080, 6.9 seconds, for repositories and relevant replies.
- `steward-short-portrait.mp4`: 1080 by 1920, 6.9 seconds, for vertical placements.
- `steward-short.gif`: a silent looping README preview linked to the landscape MP4.
- `steward-mark.svg` and `steward-mark-black.png`: the project mark supplied with the final films.

Use the full portrait or landscape launch film for social launch posts. Keep the short cut for quick introductions.
Describe v0.2.0 as a preview and keep the release's provider limits clear.
